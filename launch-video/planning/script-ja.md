# 日本語スクリプト

ナレーションのタイミングの正は [`timeline.json`](timeline.json) の `narration`。
話速の目安は約7.5モーラ/秒。各行は窓（start–end）の中に余白0.2秒以上を残して収まる長さにしてある。

## 0. ナレーションなしで成立させる（既定の編集）

既定の編集は **ナレーションなし（`NOVO`：音楽＋SFXのみ）**。X の自動再生はミュートで始まり、READMEループも無音のため、映像と画面内テキストだけで意味が通ることを前提にする。

| ナレーション | 画面内の対応 | 補う手段 |
|---|---|---|
| N1 その一行のために | S01「Terminalを開くほどでもない。」→「その一行のために。」 | 画面内テキスト |
| N2 ⌥Spaceで呼び出す | S02 `⌥ Space` チップ＋打鍵 → S03「呼べば、すぐ。」 | HUD＋実UI |
| N3 貼って、実行して、コピー | S04「貼る。実行。コピー。」が実UIの3イベントに同期 | 画面内テキスト＋実UI |
| N4 終了コードもひと目で | S05「結果も、終了コードも。」＋ `exit 0` / `ms` の下線 | コールアウト |
| N5 履歴も安全確認も | S06「履歴100件。」「危ないコマンドは、確認してから。」 | 画面内テキスト＋実UI |
| N6 一行のための、ターミナル | S08 ワードマーク＋同文 | エンドカード |

版の構成（`timeline.json` の `audioVersions`）:

| 版 | 音声 | 映像・テキスト |
|---|---|---|
| NOVO（既定） | 音楽＋SFX | 共通 |
| VO_STANDARD | ＋標準語VO、VO中は音楽を -6 dB ダッキング | 共通（再編集なし） |
| VO_KANSAI | ＋関西弁VO、同上 | 共通（再編集なし） |

ナレーションは「画面の読み上げ」ではなく「同じ内容を声の温度で補う」位置づけ。VOを足してもカット・テキストは一切動かさない。

**本人チェック項目**（収録・生成前に本人が声に出して確認）

- 「開くまでもないやん」と「開くほどでもないねん」のどちらが自分の口から自然に出るか
- N5は「確認してくれる」以上の意味（＝防いでくれる）に聞こえないか
- N6の締めを「ターミナルや」で言い切るか、「作ったで」で本人の制作物として名乗るか

## 3. 画面内テキスト（両版共通、標準語で固定）

画面内テキストは版を問わず共通にする（再レンダー範囲をナレーション差し替えだけに限定するため）。

| Shot | テキスト |
|---|---|
| S01 | Terminalを開くほどでもない。 / その一行のために。 |
| S02 | ⌥ Space |
| S03 | 01 — 呼ぶ / 呼べば、すぐ。 |
| S04 | 02 — 完結する / 貼る。 実行。 コピー。 |
| S05 | 結果も、終了コードも。 |
| S06 | 03 — 任せられる / 履歴100件。 / 危ないコマンドは、確認してから。 |
| S08 | macOS 14+ / Mini-Terminal / 一行のための、ターミナル。 / github.com/uniplanck/Mini-Terminal |

表現上の制約（READMEと実装に合わせる）:

- 「100件」は履歴の上限。「100件保存できる」以上は言わない
- 安全確認は「確認」まで。「防ぐ」「安全」単体の断定は使わない
- 「無料」「オープンソース」はリポジトリにLICENSEが入るまで使わない
