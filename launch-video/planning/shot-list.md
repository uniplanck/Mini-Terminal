# Shot List

1920×1080 / 60fps / 18.0秒 / 120 BPM（1ビート = 0.5秒 = 30フレーム）。
時間・コピーの正は [`timeline.json`](timeline.json)。この表と食い違ったら `timeline.json` を直してからこちらを合わせる。

担当の凡例: **UI** = 実アプリ録画 / **AE** = After Effects（タイポ・カメラ・合成・グレード）/ **HF** = Higgsfield生成素材。

## S01 HOOK — 0:00.00–0:02.00

| 項目 | 定義 |
|---|---|
| 画面構成 | 全面にHF_H1（黒いスモークガラス、左から細い光のスリット）。左2/3が空き。コピーはカラム2–9、ベースライン y=600 |
| UI状態 | なし |
| カーソル | なし |
| Typography | 「Terminalを開くほどでもない。」（0.15s）→「その一行のために。」（1.0s、Medium 56px）。1行目 Noto Sans JP Bold 88px / 字間 -20 / 行送り1.2。「Terminal」はInter SemiBold。左上に `00` ラベル（JetBrains Mono 18px, muted） |
| Camera | 2.0秒で 100%→103% のゆっくりしたプッシュ（AEカメラ z移動） |
| Transition | 黒から開始。1.75–2.00でコピーが上方向に16pxマスク退場。S02へはハードカット（打鍵の直前） |
| Motion | 文字は1文字ずつではなく **単語単位** のマスクリビール（0.10s stagger, 0.45s expo-out）。光のスリットは素材のまま |
| Sound / Beat | 0.0 低いパッド立ち上がり。beat 1–4 はハイハットのみ。N1開始 0.25s |
| 担当 | HF: 背景プレート / AE: タイポ・カメラ・グレード |

## S02 KEYS — 0:02.00–0:03.50

| 項目 | 定義 |
|---|---|
| 画面構成 | Mac 最下段のマクロ静止画（配列・刻印はオーナー実機写真が基準）。左から fn / control / option / command / space、option と space の間に command。ピントは option〜space 左端。左下にキーラベルHUD。仕様は [`h2-redesign.md`](h2-redesign.md) |
| UI状態 | なし |
| カーソル | なし |
| Typography | 左下 `⌥ Space` キーキャップチップ（AE製、角丸10px、Inter SemiBold 28px、hairline枠）。押下フレームでチップが2px沈む |
| Camera | 静止画のため BASE を 100%→101.5% の微プッシュ（直線）のみ |
| Transition | 打鍵の瞬間（2.95s / frame 177）に白フラッシュ1フレーム無し、代わりに **露出 +0.6EVを3フレーム** → S03へカット |
| Motion | AEで option と space を **同一フレームで同時に** 沈める（`CTRL_Press` 1本で駆動、ローカル53→57f、底打ち = 全体f177、バウンス無し、カットまで保持）。command は動かさない。手・指は出さない |
| Sound / Beat | 2.95s（beat 6直前の裏）に打鍵SFX＋キック。ここが音楽の本格スタート |
| 担当 | 静止プレート: ChatGPT制作（配列・刻印はオーナー実機写真に一致）/ AE: `PC_H2R_RIG`（キャップ切り抜き・押下・影）、HUD、露出パルス。旧 V2-H2（Higgsfield）は不採用 |

## S03 SUMMON — 0:03.50–0:06.00

| 項目 | 定義 |
|---|---|
| 画面構成 | 黒背景中央にコンパクトパネル（720×96pt → Retina 1440×192px を画面上 ~1300px幅で表示）。上1/3にラベル、下1/3にコピー |
| UI状態 | 非表示 → コンパクト表示（待機中）→ コマンド入力 `git rev-parse --short HEAD` → 実行 → `exit 0 · 12 ms`（実測値を使用） |
| カーソル | なし（キーボードのみ）。入力はリアル打鍵の録画 |
| Typography | 「呼べば、すぐ。」Noto Sans JP Bold 72px、パネル下 64px。ラベル `01 — 呼ぶ` |
| Camera | 3.5→6.0 で 104%→100% のプルバック（パネル出現の勢いを受け止める） |
| Transition | 実アプリのパネルは**アニメーションなしで即時表示**される（`makeKeyAndOrderFront`）。その即時性をそのまま見せ、beat 7にぴったり合わせる。AEで出現アニメーションは足さず、背景の極薄ビネットが1拍で立ち上がるだけ |
| Motion | キーストロークHUD（`⌘↩`）を実行フレームで0.4秒表示 |
| Sound / Beat | パネル出現 = beat 7（3.5s）。タイプ音はUI SFXで軽く、実行音をbeat 10（5.0s）付近の実測タイミングに合わせる |
| 担当 | UI: 録画 / AE: 背景・カメラ・HUD・コピー |

## S04 CLIPBOARD — 0:06.00–0:09.50（主役）

| 項目 | 定義 |
|---|---|
| 画面構成 | 左カラム（1–5）にコピー元の「テキストカード」（AE製、架空の手順メモ「タイムスタンプを日付に」と `date -u -r 1790000000 '+%Y-%m-%d %H:%M UTC'` の1行。出力 `2026-09-21 14:13 UTC` は撮影用ワークスペースで決定的）。右カラム（6–12）にパネル |
| UI状態 | ⚡（起動時にClipboardを即実行: ON）状態で待機 → `⌘C` → `⌥ Space` → 自動貼り付け → 自動実行 → 出力 → フッター「出力をコピーしました」 |
| カーソル | AE製ベクターカーソル1回のみ：テキストカード上の行をドラッグ選択（6.1–6.6s、ease-in-out）。システムカーソルは録画で非表示 |
| Typography | 3ビートのスタック「貼る。」「実行。」「コピー。」を beat 13/14/15（6.5/7.0/7.5s付近、実UIイベントに±2フレームで合わせる）で順に点灯。非アクティブ語は muted、アクティブ語は ink。ラベル `02 — 完結する` |
| Camera | テキストカード→パネルへ横パン（x −320px, 0.6s expo-in-out）、その後パネルに 100%→108% プッシュ |
| Transition | S03からはパネル位置を保ったままマッチカット（同じ画面座標） |
| Motion | `⌘C` `⌥ Space` のキーチップHUD。コピー完了時にフッターのフィードバックへ細いアクセントリング（2px, 0.3s） |
| Sound / Beat | ⌘C=クリック、パネル=スウッシュ短、実行=ティック、コピー=上昇音。N3はこの3ビートに同期 |
| 担当 | UI: 録画（自動貼り付け/実行/コピーは実機能） / AE: テキストカード、カーソル、HUD、タイポ、カメラ |

## S05 SPLIT — 0:09.50–0:12.00

| 項目 | 定義 |
|---|---|
| 画面構成 | 分割表示（900×480pt）を画面いっぱい近くまで。INPUT左 / OUTPUT右 |
| UI状態 | 分割ボタンクリック → 入力 `wc -l Sources/MiniTerminal/*.swift`（撮影用コピーのリポジトリで実行）→ 出力、フッター `exit 0 · N ms` |
| カーソル | AEベクターカーソル：分割ボタンへ移動しクリック（9.6–10.0s）。クリック時 0.9 scale 0.08s |
| Typography | 「結果も、終了コードも。」をOUTPUT下部の外側に。フッターの `exit 0` と `ms` に細いアクセント下線を順に引く（コールアウト） |
| Camera | OUTPUTペインへ 100%→118% のプッシュ＋x方向わずかにトラック。Retina素材なので拡大で解像度落ちなし |
| Transition | S04のパネルが拡張するリアルなリサイズを利用（実アプリのウィンドウ拡張） |
| Motion | コールアウト線は 0.35s expo-out、テキストは単語単位リビール |
| Sound / Beat | 分割クリック = beat 19（9.5s）。実行 = beat 21付近 |
| 担当 | UI: 録画 / AE: カーソル、コールアウト、カメラ |
