# Concept — Mini-Terminal Launch Film

## 主要価値（3つ）

| # | 価値 | 根拠（実装） | 映像で見せる瞬間 |
|---|---|---|---|
| 01 | **一瞬で呼べる** | 常駐メニューバーアプリ。グローバルショートカット（初期値 `⌥ Space`）で既存パネルを表示するだけなので、毎回コールドスタートしない | キーを押した次のビートでパネルが出る |
| 02 | **クリップボードで完結する** | 開いた瞬間の自動貼り付け → 自動実行 → 出力の自動コピー（約1秒のフィードバック）。INPUT / OUTPUT分割、exit code、実行時間 | 「貼る。実行。コピー。」の3ビート |
| 03 | **任せられる** | 最大100件のローカル履歴、↑/↓呼び出し、`rm` / `sudo` / `git reset --hard` / 複数行の実行前確認 | 履歴スクロール → 実行確認ダイアログ |

> 03の安全確認はヒューリスティックでありサンドボックスではない（README Safety節）。映像・ナレーションでは「確認する」までを言い、「防ぐ」「安全を保証」とは言わない。

## コンセプト

**「一行のための、ターミナル。」**

Terminalを開くほどでもない、数秒の作業。その「一行」だけのために設計された道具であることを、
18秒・36ビートの中で、黒いキャンバスと実UIだけで静かに証明する。

- **主役は実UI。** 生成映像は「呼ぶ前」と「呼んだ後」の空気だけを担当し、機能の説明は一切させない。
- **Swiss editorial。** 12カラムグリッド、左揃え、強いサイズコントラスト、番号ラベル（`01 — 呼ぶ`）。装飾ではなく整列で品位を出す。
- **ビートで嘘をつかない。** UIの状態変化（表示・実行・コピー完了）はすべて実録画のタイミングを基準にし、AEでは速度を盛らない。カットと文字だけを120 BPMのグリッドに合わせる。
- **静→動→静。** 暗いオブシディアンの静けさ → キー1回の打鍵 → UIの3連ビート → 光のリボンで引き → 静かなエンドカード。

## トーン

| 項目 | 方針 |
|---|---|
| 色 | 背景 `#0A0A0B`、文字 `#F5F5F7`、補助 `#8E8E93`、アクセントはmacOSシステムブルー `#0A84FF`（UIのaccentColorと一致）。成功 `#30D158` / 警告 `#FF453A` はUI内の意味がある時だけ |
| 書体 | 和文 Noto Sans JP（Bold / Medium）、欧文 Inter、コード JetBrains Mono。いずれもOFL。UI録画内のSF書体には手を加えない |
| 動き | 入り `cubic-bezier(0.16, 1, 0.3, 1)`（expo-out）、出 `cubic-bezier(0.7, 0, 0.84, 0)`。オーバーシュート禁止、バウンス禁止 |
| カメラ | 物理的に穏やか。プッシュは最大 +6%/秒、回転は使わない（S02のマクロのみ微小パララックス） |
| 音 | 120 BPMのミニマルなエレクトロ/クリック系。打鍵・実行・コピーに合わせたUI SFX。ナレーションは低めで近い距離感 |

## やらないこと

- AI生成映像でUIを描かせる・UIを生成映像の中に「それっぽく」合成する
- 実装されていない機能を想起させる（PTY、ストリーミング出力、キャンセル、タイムアウト、サンドボックス）
- 実在ユーザーのパス・履歴・クリップボード内容を映す（撮影は専用プロファイル＋架空データ）
- Appleロゴ・Apple製品の識別可能な意匠を生成させる

## 尺と配分

- 本編: **18.0秒**（1920×1080 / 60fps / 1080フレーム / 36ビート @120 BPM）
- 画面ベース素材の配分: **実UI 13.0秒（72%）/ Higgsfield 5.0秒（28%）**。After Effectsは全ショットの仕上げ（タイポ・カメラ・合成・グレード）を担当
- README用ループ: 本編 3.5–9.5秒（6.0秒、テキストなし）を主案、3.5–12.0秒（8.5秒）を代替案

## 注意（前提条件）

`docs/v0.4-ui-review.md` は v0.4 を「not an approved filming freeze」と明記している。実UI撮影は **UIフリーズ承認後** に行う。それまでに作るものはすべて差し替え可能なプレースホルダー前提。
