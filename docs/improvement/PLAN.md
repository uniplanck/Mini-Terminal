# Mini-Terminal v0.5 実装計画

作成日: 2026-11-20 / 作業ブランチ: `feat/v0.5-live-output-20261120`（`feat/v0.4-ui-polish-20261007` から分岐）/ 新バージョン: **0.5.0（build 5）**

戦略は [STRATEGY.md](STRATEGY.md) を参照。

## 順序

指示された優先順（逐次表示 → 停止 → スクロール → UI）をそのまま採る。変更する理由が監査から出なかった。
逐次表示と停止はどちらも `ShellRunner` の書き直しに乗るので、エンジンをP1で一度に置き換え、P2では停止の操作面だけを足す。

状態欄は実装後に更新する。「完了」は、その行の検証を実際に実行して通ったものだけに付ける。

## 実機確認手順

自動テストで代替できない操作の確認。隔離された `--ui-fixture` モード（専用の設定・履歴・クリップボード、ショートカットは ⌃⌥⇧Space）で行う。

```sh
bash scripts/build-app.sh
dist/Mini-Terminal.app/Contents/MacOS/Mini-Terminal --ui-fixture
```

1. **逐次表示**: `for i in $(seq 1 20); do printf "\rframe=%d" $i >&2; sleep 0.3; done` を実行し、進捗が1行で更新され、ステータスに経過時間が出ることを確認する。ffmpegがあれば `ffmpeg -f lavfi -i testsrc=duration=20:rate=30 -c:v hevc_videotoolbox -stats -y /tmp/mt.mp4` でも確認する。
2. **停止**: `sleep 60` を実行し、停止ボタン、`⌘.`、`⌃C` のそれぞれで止まることを確認する。実行中にメニューから終了し、`pgrep sleep` に残らないことを確認する。
3. **スクロール**: `seq 1 5000` を実行し、末尾へ追従すること、実行中に上へスクロールすると追従が止まり「最新へ」ボタンが出ることを確認する。50行のスクリプトを分割表示の入力へ貼り、実行中もスクロールできることを確認する。折り返しを切り替える。
4. **コンパクト表示**: `ls -la` で出力ペインが開くこと、`:` では開かないこと、3行のコマンドを貼ると入力欄が伸びることを確認する。
