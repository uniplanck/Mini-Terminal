# Mini-Terminal 0.5.0 リリースノート草稿

状態: 草稿（2026-11-20）。ブランチ `feat/v0.5-live-output-20261120`、未push・未リリース。
使い方マニュアルと紹介動画の元原稿として使えるよう、利用者から見える変化だけを書く。

## ひとことで

長いコマンドの途中経過が見えるようになり、止められるようになった。
結果はコマンド欄のすぐ下に出るので、分割表示へ切り替えなくても読める。

## 新しくできること

### 1. 実行中の出力がその場で流れる

これまでは、コマンドが終わるまで出力欄は「実行中…」のままだった。
0.5.0では、出力は届いた順にすぐ表示される。

- ffmpegの `-stats` や `curl` の進捗のように、同じ行を書き換えて進捗を示すコマンドは、Terminalと同じく1行がその場で更新される。
- エラー出力は、発生した位置に表示される。これまでは通常の出力の後ろにまとめられていた。
- ステータスバーに経過時間が出る（`実行中… 1:15`）。

### 2. 実行を止められる

実行中は「実行」ボタンが「停止」ボタンに変わる。キーボードでは `⌃C` または `⌘.`。

- 止め方はTerminalの `⌃C` と同じ。ffmpegは書き出し中のファイルを正しく閉じてから終了する。
- パイプでつないだコマンド（`a | b | c`）も、まとめて止まる。
- 2秒たっても終わらないコマンドには、段階的に強い終了要求を送る。もう一度停止を押すと、その場で強制終了する。
- 止めたコマンドのステータスは「停止しました」と表示される。履歴には残るが、途中までの出力は自動コピーされない。クリップボードの中身は保たれる。

### 3. コンパクト表示でも結果が見える

出力のあるコマンドを実行すると、コマンド欄の下に出力欄が開く。
出力のないコマンド（`mkdir foo` など）では開かず、これまでどおり1行のままで終わる。

### 4. 長いコマンドが全部見える

- コンパクト表示の入力欄は、貼り付けた内容に合わせて最大6行まで伸びる。それ以上はスクロールできる。長いワンライナーは折り返して表示される。
- 実行中も、入力欄をスクロールして選択・コピーできる（編集だけができない）。これまでは実行中、スクロールもできなかった。
- 引用符やハイフンが「スマート引用符」などに自動で置き換わらなくなった。貼り付けた文字がそのままShellに渡る。

### 5. 長い出力を読みやすく

- 出力欄は、最下部を見ている間だけ新しい出力に追従する。上へスクロールして読み始めると、追従は止まる。
- 追従が止まっている間は、出力欄の右下に「最新の出力へ」ボタンが出る。押すか、自分で最下部までスクロールすると追従に戻る。
- 長い行は折り返して表示する。分割表示の出力欄ヘッダーにある折り返しボタンでオフにすると、横スクロールで読める（`ls -l` や表形式の出力向け）。設定は次回以降も保たれる。
- 実行中でも、コピーボタンでそこまでの出力をコピーできる。

### 6. 状態表示

- 所要時間は長さに応じて `850 ms` / `12.3 s` / `20m 05s` / `1h 02m 03s` と表示する。これまでは常にミリ秒だった。
- 大量の出力で古い部分が省略されたときは、ステータスバーに「古い出力を省略」と出る。

## キー操作

| 場所 | キー | 動作 |
| --- | --- | --- |
| コマンド欄（上部） | `Return` | 実行 |
| コマンド欄（上部） | `⇧Return` / `⌥Return` | 改行 |
| コマンド欄（上部） | `↑` / `↓` | 1行目で `↑`、最終行で `↓` を押すと履歴を呼び出す。それ以外では行を移動する |
| 分割表示の入力欄（左） | `Return` | 改行 |
| どこでも | `⌘Return` | 実行 |
| どこでも（実行中） | `⌃C` / `⌘.` | 停止。2回目で強制終了 |
| どこでも | `Esc` | パネルを閉じる。実行中のコマンドは止まらず、開き直すと続きが見える |

## これまでと変わる挙動

移行時に気づく可能性があるものを挙げる。

| 項目 | 0.4まで | 0.5.0 |
| --- | --- | --- |
| 出力の表示タイミング | 終了後にまとめて | 実行中に逐次 |
| stdoutとstderrの順序 | stdout全体の後にstderr | 出力された順 |
| コンパクト表示の出力 | 表示なし（コピーのみ） | 出力があればコマンド欄の下に表示 |
| 長い行 | 折り返しなし・横スクロール | 既定で折り返し（切り替え可） |
| `sleep 100 &` のように子を残すコマンド | 子が終わるまで「実行中」 | シェルが終わった時点で完了。その後に子が書いた出力は表示しない |
| 実行中にアプリを終了 | コマンドは動き続ける | コマンドも終了する |
| 出力コピーボタン | 実行完了後は常に有効 | 出力があるときだけ有効（実行中も可）。空の出力でクリップボードを上書きしない |
| 色などの制御文字（ANSIエスケープ） | そのまま文字として表示 | 取り除いて表示 |
| 文字化けするバイトを含む出力 | 出力全体が空になる | 該当箇所だけ `�` になり、残りは表示 |
| シグナルで終了したコマンドの終了コード | シグナル番号 | Shellと同じ `128 + シグナル番号`（例: 143） |
| 出力の前後の空行 | 先頭と末尾を削除 | 末尾のみ削除 |
| 履歴に保存する出力 | 全文 | 1件あたり末尾の約20 KB。超えた分は先頭に `[…]` を付けて省略 |
| 所要時間の表記 | 常に `ms` | `ms` / `s` / `m s` / `h m s` |

既存の履歴はそのまま残る。上限が適用されるのは0.5.0以降に実行したコマンドだけである。

## 制限

- 端末（PTY）は割り当てない。`vim`、`top`、`ssh` のパスワード入力など、対話型のプログラムは動かない。標準入力は空で、入力を待つコマンドはすぐに入力終了として扱われる。
- 画面に保持する出力は直近の約2 MB。超えた分は古い行から省略される。全文が必要な場合はファイルへリダイレクトする（`cmd > out.txt`）。
- 出力が非常に多いコマンドは、表示の速度に合わせて流れる。Terminalに大量出力したときと同じ挙動で、`yes` のようなコマンドでも画面は固まらず停止できる。
- 同時に実行できるコマンドは1つ。

## 紹介動画・マニュアル向けの実演シナリオ

ビルドした.appを隔離モード（`--ui-fixture`）で起動し、アクセシビリティ経由の操作で確認した流れ。
停止は停止ボタンで、コマンドの入力は入力欄への直接設定で確認している。`⌃C` などの実キー入力と、⌥ Space からの貼り付け、トラックパッドでのスクロールは撮影前に手で確認する。

1. **進捗が見える**（約15秒）: `ffmpeg -i in.mov -c:v hevc_videotoolbox -stats out.mp4` を貼って実行。`frame= … speed=…` の行がその場で更新され、ステータスバーの経過時間が進む。
2. **止められる**（約10秒）: 同じエンコードの途中で停止ボタン（または `⌃C`）。「停止しました」と表示され、出力の最後に ffmpeg の `Exiting normally, received signal 2.` が出る。書き出したファイルは再生できる。
3. **その場で結果**（約5秒）: ⌥ Space → `ls -la` → Return。パネルが下へ伸びて一覧が出る。続けて `mkdir demo` を実行すると、出力がないためパネルは1行のまま終わる。
4. **長いコマンドを貼る**（約10秒）: 4〜5行のスクリプトをコピーして ⌥ Space。入力欄が行数に合わせて伸び、全体を確認してから実行できる。
5. **長い出力を読む**（約10秒）: `seq 1 5000` を実行し、上へスクロール。追従が止まり「最新の出力へ」ボタンが出る。押すと最下部へ戻る。
